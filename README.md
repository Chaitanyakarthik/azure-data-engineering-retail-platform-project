🛒 Azure Retail Analytics Data Platform
Lakehouse Architecture • Medallion Design • Scalable ETL Pipelines
📌 Project Overview

Designed and implemented a modern, scalable Azure-based data engineering platform to enable retail analytics using the Medallion Architecture (Bronze, Silver, Gold).

Built end-to-end data pipelines integrating structured data (Azure SQL Database) and semi-structured data (REST API JSON) into a centralized lakehouse architecture. Leveraged Azure Data Factory for orchestration and Azure Databricks (Apache Spark) for distributed processing, transforming raw data into analytics-ready datasets stored in Delta Lake format.

Delivered interactive Power BI dashboards to provide insights into sales performance, product trends, store metrics, and customer behavior.

🎯 Key Impact
✔ Unified multi-source data into a centralized analytics platform
✔ Improved data quality and consistency through layered transformations
✔ Enabled scalable distributed processing using Apache Spark
✔ Delivered business insights through interactive Power BI dashboards
